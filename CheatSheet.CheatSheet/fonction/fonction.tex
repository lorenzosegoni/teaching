\section{Fonctions}
Structure Générale:

\begin{verbatim}
def nom_fo(p_obl, p_opt=val):
    # Corps de la fonction
    [instructions]
    return [valeur_a_renvoyer]
\end{verbatim}

\begin{itemize}
\item \texttt{def} : Mot-clé déclarant la création de la fonction.
\item \texttt{(...)} : Déclare les paramètres.
\item \texttt{:} : Obligatoire
\item \texttt{Indentation} : Délimite formellement ce qui appartient (ou non) à la fonction.
\item \texttt{return} : Renvoie le résultat au programme principal. Son exécution termine immédiatement la fonction. Sans return explicite, la fonction renvoie None.
\end{itemize}
